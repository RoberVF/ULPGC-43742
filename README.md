# PROGRAMACION WEB - 43742

Esta asignatura de Programación Web ha consistido en un recorrido integral por el desarrollo de aplicaciones modernas, partiendo desde los fundamentos de maquetación en HTML5 y CSS3 hasta la implementación de sistemas complejos bajo el framework Laravel. El núcleo del aprendizaje se ha centrado en dos proyectos principales: un Marketplace E-commerce completo con gestión de roles (clientes, productores y vendedores) y una Práctica Evaluable basada en el patrón MVC para la gestión técnica de un huerto ecológico. En esta última, se desarrolló una arquitectura robusta para el control de producciones, permitiendo monitorizar costes, fechas de cultivo y valores de mercado de forma dinámica, integrando relaciones de base de datos Eloquent y componentes de Livewire.

A lo largo del curso, se ha consolidado el manejo de un stack tecnológico compuesto por PHP 8.x, TailwindCSS, MySQL y el uso de herramientas como Composer y Vite. Además del desarrollo de funcionalidades backend como rutas dinámicas, controladores y seeders, se ha puesto especial énfasis en la experiencia de usuario y la persistencia de datos. Este repositorio refleja la evolución desde los primeros scripts básicos en PHP hasta la creación de plataformas web escalables y funcionales, cumpliendo con los estándares actuales de la industria y las metodologías de desarrollo aprendidas en la ULPGC.
